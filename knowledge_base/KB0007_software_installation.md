# Software Installation and the Software Catalogue

Employees do not have local administrator rights. Approved software is installed through the Software Catalogue in the self-service portal or by asking the IT Helpdesk chatbot.

## How to request software
1. Ask the chatbot, for example "I need Visual Studio Code installed", or browse the Software Catalogue.
2. A ServiceNow service request (REQ) is created automatically.
3. Free, pre-approved software (such as Visual Studio Code, Google Chrome, 7-Zip, Zoom, Slack, Git and Postman) is provisioned automatically, usually within 15 minutes.
4. Licensed software (such as Adobe Acrobat Pro, Microsoft Visio, Microsoft Project or JetBrains IntelliJ IDEA Ultimate) needs line-manager approval before provisioning.
5. You receive status updates as the request moves from Submitted to Approved, Provisioning and Completed.

## After installation
- Restart the application or sign out and in again if it does not appear in the Start menu.
- Licensed applications are activated with your corporate account.

## Software not in the catalogue
Software that is not in the catalogue needs a security and licence review. Submit a "New software evaluation" request; reviews take 5-10 business days.

## When to escalate
Contact Software Distribution if provisioning has failed or the request has been in Provisioning for more than 24 hours.
