# Requesting Application Access

Access to business applications (SAP, Salesforce, Workday, Jira, shared drives) is role based and must be approved by the application owner.

## How to request access
1. Submit an access request in the self-service portal, or tell the chatbot which application and role you need, for example "I need read access to the Finance shared drive".
2. Include the business reason and the role or permission level.
3. Your line manager approves first, then the application owner.
4. Access is granted automatically after approval, usually within 4 business hours.

## "Access denied" errors
- If you had access before, your role may have been removed during the quarterly access review. Submit a new request.
- Sign out and in again after access is granted so the new group membership takes effect.
- Clear the browser cache for web applications.

## When to escalate
Raise an incident with Identity & Access Management if access was approved more than one business day ago but still does not work.
