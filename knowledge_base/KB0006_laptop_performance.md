# Laptop Performance and Slowness

Use this guide when the laptop is slow to start, applications freeze, or the fan runs constantly.

## Quick checks
1. Restart the laptop. Laptops that have not been restarted for more than 7 days often slow down because updates are pending.
2. Open Task Manager (Ctrl+Shift+Esc) or Activity Monitor and sort by CPU and memory to find the application using the most resources.
3. Check free disk space. Keep at least 15% free on the system drive.

## Clean-up steps
1. Clear temporary files: Settings > System > Storage > Temporary files. The AI helpdesk agent can run a remote temp-file and cache clean-up.
2. Close browser tabs you do not need; each tab can use 100-300 MB of memory.
3. Turn off unnecessary startup apps: Task Manager > Startup.
4. Install pending Windows and Company Portal updates, then restart.
5. Run a quick antivirus scan from Microsoft Defender.

## Hardware indicators
- Laptops older than 4 years qualify for a hardware refresh.
- A battery that drains in under 2 hours or a laptop that overheats needs a Desktop Support inspection.

## When to escalate
Raise an incident for Desktop Support if the laptop stays slow after the clean-up steps, shows blue-screen errors, or makes unusual noises.
